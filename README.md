# 🎯 Number Guessing Game

Welcome to the **Number Guessing Game** — a fun and interactive command-line game written in Python!

## 🕹️ How to Play

The computer randomly selects a secret number between **1 and 100**. You have **7 chances** to guess it correctly.

With each guess, you'll get a colorful hint that tells you how close you are:

- 🔥 **Super Hot** – You're very close!
- 🌡️ **Warm** – You're getting closer.
- ❄️ **Cold** – You're far off.
- 🎉 **Correct** – You guessed it!

Your goal is to guess the number within the limited attempts.

## 🧠 Features

- 🎨 Colorful terminal output (for better UX)
- 🧊 Hot/Warm/Cold feedback system
- 💻 Simple Python script with zero dependencies
- 🔁 Reusable and easily customizable
